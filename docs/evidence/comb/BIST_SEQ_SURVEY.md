## 7. Frame format
- Header (`host_app_k5/qpsk_frame.h:4-11`): [0..1] 0x51 0x4B, [2..3] len LE, [4..7] seq LE, [8..11] CRC32, payload zero-padded; encoder `qpsk_frame.c:113,127`, decoder `:155,164`. CRC reflected poly 0xEDB88320 init/final 0xFFFFFFFF over HDR+len bytes with the CRC field zeroed (`qpsk_frame.c:5-17`). F1536_PKT_BYTES=1528 (191×64 b), F1536_TX_XFER_BYTES=3080 (385×8, air frame; wordFirst/TLAST on the air-frame boundary) `qpsk_frame.h:38-46`.
- Scrambler `HDL_Data_Scrambler.v` x^7+x^4+1, hard-disabled (`:71` EnableScrambling=0 → passthrough `:281`); no RX descrambler exists → decoder-output bytes == TX bytes. WHITEN is host-only PN9 (`qpsk_frame.c:74-98`); must be off for fabric checkers (`bringup_r2r3.sh:41` WHITEN=0).
